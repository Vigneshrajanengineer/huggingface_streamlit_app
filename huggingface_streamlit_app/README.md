# Hugging Face Streamlit App

A simple Streamlit app using Hugging Face Transformers for:
- Sentiment Analysis
- Text Generation
- Summarization

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy on Hugging Face Spaces
1. Create a new Space: https://huggingface.co/spaces
2. Choose Streamlit SDK
3. Upload this repo (streamlit_app.py + requirements.txt)
